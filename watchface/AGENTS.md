# watchface — AI Agent Instructions

This file contains rules specific to the **watchface** application: the Wear OS watch face, written in
Google's declarative Watch Face Format (WFF) and built into an APK with Gradle.
The root [AGENTS.md](../AGENTS.md) and [PERMISSIONS.md](../ai_tooling/PERMISSIONS.md) apply here too.

**If your workspace is this folder and not the repository root** (the IDE was opened on `watchface` alone):

1. Read `../AGENTS.md` and `../ai_tooling/PERMISSIONS.md` now, unless they are already in your context, and follow them.
2. Tell the user once, at the start: *opening the repository root in the IDE is recommended. The project's skills,
   MCP servers and agent rules are published only there, so some of them may be missing in this window.*

## Critical Version Constraints

| Constraint | Why |
|-----------|-----|
| Watch Face Format **2** (`com.google.wear.watchface.format.version` in `app/src/main/AndroidManifest.xml`) | Only WFF v2 elements and expressions are allowed; the validator is run with version `2` |
| minSdk **36**, targetSdk **37**, compileSdk **37** (`app/build.gradle.kts`) | Wear OS 6+ only; needs Android SDK Platforms 36 and 37 |
| Android Gradle Plugin **9.4.1** (`gradle/libs.versions.toml`), Gradle **9.6.0** (`gradle/wrapper/gradle-wrapper.properties`) | Use the wrapper (`gradlew.bat`), never a globally installed Gradle |
| Gradle daemon JVM **25** (`gradle/gradle-daemon-jvm.properties`, provisioned through the foojay resolver in `settings.gradle.kts`) | Generated by `updateDaemonJvm`; do not edit by hand |
| `enableKotlin = false`, no dependencies (`app/build.gradle.kts`) | A WFF watch face carries no runtime code (never-do below) |
| Application id `com.pansar.watchface_total_view` (`app/build.gradle.kts`), publisher `PanSar` (`AndroidManifest.xml`) | They identify the published watch face: never change them unasked |

## Things AI Agents Must Never Do

- Never add Kotlin or Java classes, activities or services, and never set `hasCode` to true: all watch face logic is declarative
  WFF XML in `app/src/main/res/raw/watchface.xml` (layouts, complications, user settings, colour bindings, ambient mode).
- Never commit a change to `watchface.xml` or its resources without a clean validator run and a successful
  `.\gradlew.bat assembleDebug` (Commands below).

## Commands

Run from `watchface/`:

- **Prepare**: none (Gradle downloads its distribution, the daemon JVM and AGP on the first build)
- **Run**: `.\gradlew.bat installDebug` with a watch or emulator connected (`custom-watchface-device-deploy`)
- **Unit tests**: none
- **E2E tests**: none
- **Lint**: `java -jar "tools\wff-validator.jar" 2 "app/src/main/res/raw/watchface.xml"` (Google's WFF validator)
- **Build**: `.\gradlew.bat assembleDebug`; release: `.\gradlew.bat assembleRelease`

## Adding or Updating Dependencies

- The app has no library dependencies. AGP is raised in `gradle/libs.versions.toml`, Gradle in
  `gradle/wrapper/gradle-wrapper.properties`, the daemon JVM with `.\gradlew.bat updateDaemonJvm` (the header of
  `gradle/gradle-daemon-jvm.properties`).
- **Notes**: a new AGP may need a newer Gradle; raise both together and run **Lint** and **Build** afterwards.
